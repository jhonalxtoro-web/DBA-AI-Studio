# LAB-001 - SQL Server Wait Statistics

## Objetivo

Analizar las principales Wait Statistics de SQL Server,
identificar los recursos involucrados y relacionar las esperas
con problemas de rendimiento.

## Nivel

Intermedio

## Categoría

Performance

## Tecnologías

- SQL Server
- T-SQL
- DMVs
- Query Store

## Etapas

1. Setup
2. Workload
3. Diagnóstico
4. Análisis
5. Optimización
6. Validación
7. Documentación

## Resultado esperado

Identificar las principales esperas de la instancia y determinar
si existe presión relacionada con CPU, memoria, I/O, bloqueos,
paralelismo u otros componentes.

## Regla de análisis

Una Wait Statistic no debe analizarse de forma aislada.
Debe correlacionarse con CPU, memoria, I/O, consultas,
bloqueos y comportamiento histórico.

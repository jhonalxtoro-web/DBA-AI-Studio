# SQL Server Laboratory Standards

Every laboratory should follow this structure when applicable:

01 - Setup
02 - Baseline
03 - Workload
04 - Diagnostics
05 - Analysis
06 - Optimization
07 - Validation
08 - Cleanup
09 - Documentation

A laboratory does not need every file immediately, but the progression should be clear.

## Required metadata

Each lab should document:

- Lab ID
- Title
- Objective
- Difficulty
- SQL Server version
- Prerequisites
- Estimated duration
- Risks
- Cleanup requirements

## Performance labs

Capture:

- baseline
- workload
- diagnostic evidence
- intervention
- post-intervention evidence

## Learning objective

The user should understand not only what command to execute, but why the command is executed and how to interpret its result.
